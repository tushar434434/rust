# 🦀 Rust Journey

Welcome to my Rust learning repository!

This repository documents my journey of learning Rust by completing **The Rust Programming Language (TRPL)** book. It contains chapter-wise examples, exercises, experiments, and mini-projects that helped me understand Rust's unique concepts and build a strong foundation in systems programming.

## 🛠️ Getting Started

Clone the repository:

```bash
git clone https://github.com/tushar434434/rust-learning.git
cd rust-learning
```

Run any example:

```bash
cd ownership
cargo run
```

Run tests:

```bash
cargo test
```
